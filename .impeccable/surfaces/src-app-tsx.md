# Home demo surface

## Scope and mode

- Primary target: `src/App.tsx`; related presentation targets: `src/MyModal.tsx`, `src/app.css`, and `index.html`.
- Visitor mode: Persuade.
- Audience: React developers evaluating the package for the first time.
- Job: understand the difference between `show()`, `hide()`, and `destroy()` quickly, then try or install the package.

## Direction

- Approved direction: Lifecycle Inspector, composition A1 split workbench.
- Approved comp: `.impeccable/mocks/lifecycle-inspector-a1-split.png`.
- Desktop geometry: shared `34% / 66%` header and hero axis, `74px` header, approximately `552px` hero body, and proof beginning near `y=626` at `1440 × 1000`.
- First viewport: concise offer and install action on the left; a dominant modal specimen and truthful live telemetry on the right.
- Memorable moment: the visitor hides a typed draft, reopens the modal, and watches mounted, visible, and draft state prove the lifecycle contract.
- Visual world: bright cool instrument paper, deep navy type, committed cobalt regions, amber reserved for preserved state, thin measurement rules, and typography that separates persuasion from telemetry.

## Content and constraints

- Preserve the existing package API and demo behavior.
- Use only real project facts and current package destinations.
- No customer, adoption, benchmark, or unverified performance claims.
- Keep keyboard operation, dialog semantics, focus treatment, reduced motion, and responsive behavior complete.

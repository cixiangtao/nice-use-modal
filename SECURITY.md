# Security policy

English | [简体中文](SECURITY.zh-CN.md)

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/cixiangtao/nice-use-modal/security/advisories/new)
to share the affected version, impact, reproduction steps, and any suggested fix.
Please avoid including real credentials, private user data, or unrelated sensitive
information.

Reports are evaluated against the latest published version. Support for older
versions is considered case by case. A response or remediation deadline is not
guaranteed, but confirmed issues will be handled as promptly as practical.

## Public disclosure

Please allow time to investigate and prepare a fix before publishing details.
When appropriate, remediation will be documented in the changelog and a new npm
version.

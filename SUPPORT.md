# Support

English | [简体中文](SUPPORT.zh-CN.md)

Use [GitHub Issues](https://github.com/cixiangtao/nice-use-modal/issues) for:

- reproducible bugs in nice-use-modal;
- incorrect public types or documentation;
- focused feature requests for the library.

Include the package version, React version, browser or runtime, a minimal
reproduction, expected behavior, and actual behavior.

Questions about React itself, a UI library, or application-specific modal design
are outside this project's support scope. Security reports must follow
[SECURITY.md](SECURITY.md) and remain private until they are resolved.
